# Image Requirements for Production Projects

For **proprietary Quark projects**, you can create:

## Architecture Diagrams (Recommended)

Create clean architecture diagrams showing:
- System components and data flow
- Technology stack icons
- Service interactions
- Key design decisions

**Tools to use:**
- Draw.io (free, web-based)
- Excalidraw (free, minimal style)
- Figma (professional)
- PowerPoint/Google Slides (export as PNG)

## Example Diagram Content

For **AI Document Structuring Service**:
- Flow: Document Upload → Azure AI → Mapping Layer → Quark Schema
- Show components: Spring Boot, Azure AI Document Intelligence, PostgreSQL
- Highlight 80% time reduction metric

For **Quark MCP Server**:
- Flow: AI Agent → MCP Server → Platform APIs
- Show tool registry, auth layer, API gateway

For **Multi-Tenant License Manager**:
- Data model diagram (Licenses, Features, Tenants)
- Hierarchical permission graph visualization

For **Keycloak SSO Migration**:
- Before/After architecture comparison
- Parallel auth flow diagram

For **Publishing Performance Optimization**:
- Performance profiling results (before/after charts)
- S3 caching layer diagram

## Naming Convention

- **cover-01.jpg** (main architecture diagram)
- **cover-02.jpg** (results/metrics visualization)
- **cover-03.jpg** (optional: detailed component diagram)

## Image Specifications

- **Aspect Ratio**: 16:9 (1920×1080px or 1600×900px)
- **Format**: JPG or PNG
- **File Size**: Under 500KB (compress if needed)
- **Style**: Clean, professional, minimal (avoid cluttered diagrams)
