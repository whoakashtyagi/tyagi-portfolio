# Image Requirements for GitHub Projects

For **public GitHub projects** (Spring Boot RabbitMQ & Face Mask Detection):

## Option 1: Screenshots from Repository

- Clone/download your GitHub project
- Run the application locally
- Capture screenshots of the running application

## Option 2: Architecture Diagrams

Create simple diagrams showing:
- **Spring Boot RabbitMQ**: Producer → RabbitMQ → Consumer flow
- **Face Mask Detection**: Video frame → Face detection → Model inference → Bounding boxes

## Suggested Content

### Spring Boot RabbitMQ (cover-01.jpg)
- Architecture diagram: Two services + RabbitMQ broker
- Show message flow with arrows
- Include Docker Compose logo

### Face Mask Detection (cover-01.jpg)
- Screenshot of application detecting faces with bounding boxes
- OR system flow diagram: Camera → OpenCV → MobileNetV2 → Output
- Show "Mask" and "No Mask" predictions with confidence scores

## Tools

- **Screenshot**: Run the app and capture with Snipping Tool (Windows) or macOS Screenshot
- **Diagram**: Draw.io, Excalidraw, or hand-drawn + digitized

## Naming

- **cover-01.jpg** (primary image)
- **cover-02.jpg** (optional: code snippet or results)
