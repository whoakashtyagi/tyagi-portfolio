# Image Requirements for Prapper AI Project

Add project screenshots to this directory with the following naming convention:

## Required Images

1. **cover-01.jpg** (16:9 aspect ratio, ~1920×1080px)
   - Main dashboard or homepage of Prapper AI
   - Shows AI agent builder interface
   - High quality screenshot from https://prapper-ai.vercel.app/

2. **cover-02.jpg** (16:9 aspect ratio, ~1920×1080px)
   - Chat interface showing streaming conversation
   - Real-time AI responses in action
   - OR document processing/RAG demonstration

## Optional Additional Images

- **cover-03.jpg** - Embeddable widget interface
- **cover-04.jpg** - Lead management dashboard
- **cover-05.jpg** - Document upload and processing UI

## Tips

- Use browser dev tools to capture clean screenshots (remove personal data)
- Ensure consistent lighting/theme across screenshots
- Crop to remove browser chrome for cleaner look
- Compress images (use TinyPNG or similar) to keep file sizes under 500KB each
