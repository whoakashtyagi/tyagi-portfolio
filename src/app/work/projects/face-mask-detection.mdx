## Overview

A real-time face mask detection system built during the COVID-19 pandemic (2021). The system:
- Processes **live video frames** from webcams or CCTV cameras
- Detects **faces** using OpenCV's Haar Cascade classifier
- Classifies **mask vs. no-mask** using a fine-tuned MobileNetV2 model
- Draws **bounding boxes** with labels and confidence scores

**Built in Python** — which I'd never used seriously before this project. It was my first deep dive into machine learning and computer vision, and it forced me to learn an entirely new tech stack (TensorFlow, Keras, OpenCV) while shipping something functional.

## The Problem

In 2021, COVID-19 was peaking. Public spaces needed to **enforce mask mandates**, but manual monitoring wasn't scalable. Security personnel couldn't watch every camera feed or check every person entering a building.

**Automated mask detection** could:
- Monitor CCTV feeds in real-time
- Alert security when people without masks are detected
- Generate compliance reports for authorities
- Reduce manual monitoring workload

Existing solutions were either too expensive (commercial CV systems) or too inaccurate (simple template matching).

## Solution: Transfer Learning on MobileNetV2

### Why Transfer Learning?
Training a CNN from scratch requires:
- Massive datasets (millions of images)
- Significant compute resources (GPUs for days)
- Deep expertise in model architecture design

**Transfer learning** allows you to:
- Start with a **pre-trained model** (trained on ImageNet with 1M+ images)
- **Fine-tune** the final layers for your specific task (mask detection)
- Achieve good accuracy with **smaller datasets** (thousands, not millions)

### Model Architecture

**Base Model**: MobileNetV2 (pre-trained on ImageNet)  
- Chosen for **inference speed** on constrained hardware (real-time video requires <50ms per frame)
- A full ResNet would be more accurate but too slow for real-time processing

**Fine-Tuning**:
- Freeze base layers (keep ImageNet features)
- Add custom classification head:
  - Global Average Pooling
  - Dense layer (128 units, ReLU)
  - Dropout (0.5)
  - Output layer (2 units: `with_mask`, `without_mask`, softmax)

**Training**:
- Dataset: ~3,800 images (masked and unmasked faces in varied lighting and angles)
- Augmentation: Random rotation, zoom, horizontal flip (to improve generalization)
- Optimizer: Adam with learning rate 0.0001
- Loss: Categorical cross-entropy
- Epochs: 20 (early stopping if validation loss stops improving)

### System Flow

```
Webcam / CCTV Feed
        ↓
OpenCV Video Capture
        ↓
Read Frame (640×480)
        ↓
Face Detection (Haar Cascade)
    ├─ No faces detected → Next frame
    └─ Faces detected → Crop each face
                ↓
        Resize to 224×224 (MobileNetV2 input size)
                ↓
        Normalize pixel values (0-1 range)
                ↓
        Model Inference (MobileNetV2)
                ↓
        Prediction: [with_mask: 0.95, without_mask: 0.05]
                ↓
        Draw bounding box + label
                ↓
        Display annotated frame
```

**Latency**: ~30ms per frame on CPU (achieves 30 FPS for real-time processing)

## Implementation Highlights

### 1. Data Preprocessing
```python
from tensorflow.keras.preprocessing.image import ImageDataGenerator

datagen = ImageDataGenerator(
    rescale=1./255,              # Normalize pixel values
    rotation_range=20,           # Random rotation ±20 degrees
    zoom_range=0.15,             # Random zoom
    width_shift_range=0.2,       # Horizontal shift
    height_shift_range=0.2,      # Vertical shift
    horizontal_flip=True,        # Random horizontal flip
    fill_mode='nearest'
)

train_generator = datagen.flow_from_directory(
    'dataset/train',
    target_size=(224, 224),
    batch_size=32,
    class_mode='categorical'
)
```

**Why augmentation matters**: Without it, the model memorizes training images (overfits). Augmentation creates synthetic variations, improving generalization to real-world lighting, angles, and occlusions.

### 2. Transfer Learning Setup
```python
from tensorflow.keras.applications import MobileNetV2
from tensorflow.keras.layers import Dense, GlobalAveragePooling2D, Dropout
from tensorflow.keras.models import Model

# Load pre-trained base model
base_model = MobileNetV2(
    weights='imagenet',
    include_top=False,  # Exclude original classification head
    input_shape=(224, 224, 3)
)

# Freeze base model layers
base_model.trainable = False

# Add custom classification head
x = base_model.output
x = GlobalAveragePooling2D()(x)
x = Dense(128, activation='relu')(x)
x = Dropout(0.5)(x)
predictions = Dense(2, activation='softmax')(x)  # 2 classes: with_mask, without_mask

model = Model(inputs=base_model.input, outputs=predictions)
```

### 3. Real-Time Detection
```python
import cv2
import numpy as np
from tensorflow.keras.models import load_model

# Load trained model
model = load_model('mask_detector.h5')

# Load face detector
face_cascade = cv2.CascadeClassifier('haarcascade_frontalface_default.xml')

# Start video capture
cap = cv2.VideoCapture(0)  # 0 = default webcam

while True:
    ret, frame = cap.read()
    if not ret:
        break
    
    # Detect faces
    gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
    faces = face_cascade.detectMultiScale(gray, scaleFactor=1.1, minNeighbors=5)
    
    for (x, y, w, h) in faces:
        # Extract face region
        face = frame[y:y+h, x:x+w]
        face_resized = cv2.resize(face, (224, 224))
        face_normalized = face_resized / 255.0
        face_input = np.expand_dims(face_normalized, axis=0)
        
        # Predict
        prediction = model.predict(face_input)
        label = "Mask" if prediction[0][0] > 0.5 else "No Mask"
        confidence = prediction[0][0] if label == "Mask" else prediction[0][1]
        
        # Draw bounding box
        color = (0, 255, 0) if label == "Mask" else (0, 0, 255)
        cv2.rectangle(frame, (x, y), (x+w, y+h), color, 2)
        cv2.putText(frame, f"{label} ({confidence:.2f})", (x, y-10),
                    cv2.FONT_HERSHEY_SIMPLEX, 0.7, color, 2)
    
    # Display frame
    cv2.imshow('Face Mask Detector', frame)
    
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break

cap.release()
cv2.destroyAllWindows()
```

## Challenges & Solutions

### Challenge 1: Dataset Quality
**Problem**: Publicly available mask datasets had biased samples (mostly young adults, good lighting, frontal faces).

**Solution**: 
- Curated custom dataset with diverse demographics
- Included varied angles (profile, tilted heads)
- Added low-light and occluded samples (masks covering mouth only, glasses, hats)
- Resulted in ~3,800 images total

### Challenge 2: Model Selection — Accuracy vs. Speed
**Problem**: ResNet50 achieved 98% accuracy but took ~150ms per frame (too slow for real-time). MobileNetV2 was faster but initially 92% accurate.

**Solution**: 
- Chose **MobileNetV2** for inference speed (<50ms)
- Improved accuracy through **data augmentation** and **fine-tuning hyperparameters**
- Final accuracy: **95%** (acceptable trade-off for real-time performance)

**Key Insight**: In production CV systems, **latency matters as much as accuracy**. A 98% accurate model that processes 5 FPS is less useful than a 95% accurate model at 30 FPS.

### Challenge 3: False Positives on Partially Covered Faces
**Problem**: Masks worn incorrectly (under nose) were sometimes classified as "with mask."

**Solution**: 
- Added training samples of **incorrectly worn masks** labeled as "without_mask"
- Improved model's ability to detect proper mask coverage
- Not perfect, but reduced false positives significantly

### Challenge 4: Face Detection Failures
**Problem**: Haar Cascade struggles with:
- Side profiles (detects frontal faces best)
- Occlusions (hats, scarves blocking forehead)
- Extreme lighting (backlighting, shadows)

**Solution**: 
- Tuned `scaleFactor` and `minNeighbors` parameters for better detection
- Considered switching to **DNN-based face detectors** (e.g., SSD with ResNet) for production deployment
- Trade-off: DNN detectors are more accurate but slower (would reduce FPS)
